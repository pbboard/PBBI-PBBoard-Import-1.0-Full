# Security Policy

## Supported Versions
We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within PBBI, please report it privately through the **"Security"** tab on GitHub or via the "Private vulnerability reporting" feature.

Please do not open a public issue for security-related items. We appreciate your help in keeping the PBBoard community safe!
